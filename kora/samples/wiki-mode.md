Wiki distillation

Wiki mode turns raw source documents into durable Markdown pages.

Each wiki page aims to capture:

- A stable title and slug
- A short summary
- Key points
- Concepts worth remembering
- Open questions for later work

Pages can mention each other. Kora performs light linkification so titles become [[slug|title]] references.

This is intentionally thinner than WeKnora's production Wiki Mode (which includes task queues, taxonomy, graph visualization, and large-scale ingest). The prototype proves the product idea: knowledge should not stay as opaque chunks forever — it should evolve into readable, linked pages.
